# 任务单模板（派给执行 Agent）

协议：**任务单进，清单和报告出。** 任务单必须自包含，不依赖任何聊天记录；这样命令行 Codex、桌面版 Codex、别的 Agent、甚至人手动执行，都能接。

## 目录
1. 素材搜索任务单 `TASK.md`
2. 回报格式：`MANIFEST.csv` 与 `REPORT.md`
3. 给执行 Agent 的通用开场提示词（可直接粘贴）
4. 登录态网页任务的写法

---

## 1. 素材搜索任务单

```markdown
# TASK · <任务编号>

- 项目 / 主题：
- 发令日期：
- 输出目录：`<库>/assets/_inbox/<任务编号>/`（审核通过后由负责审核的模型移入库并写台账；不要直接写进项目文件夹）
- 风格依据：<视觉方向一句话；全局禁止项>

## 统一规格
- 视频：1920×1080 以上，30fps，H.264，yuv420p，**去掉音轨**，每个镜头至少 6 秒
- 图片：保留原始最大分辨率，另存 3840px 宽 JPG
- 每个编号交付 **2–3 个候选**（文件名加 _c1/_c2/_c3），由我挑选
- 授权：商用可用（CC0 / 公有领域 / CC-BY 注明作者）；授权不明确的不下载

## 全局禁止
<例：可读的无关文字、水印、塑料皮肤的 AI 人像、观众容易误读的宗教或文化符号……>

## 清单
| 编号 | 用于（时间码 / 口播原话） | 叙事功能 | 要什么 | 首选来源 / 搜索词 | 验收标准（任一条不满足就不交付）|
|---|---|---|---|---|---|

## 铁律
1. 不删除、不移动、不覆盖任何已有文件；新版本加 _v2 后缀。
2. 只在输出目录内写入。
3. 下载后做技术检查：能播放、分辨率和时长正确、无水印、无可读的无关文字、首中尾三帧正常。不通过记为 rejected_by_check。
4. 所有文本文件用 UTF-8。
5. 有歧义时，在 REPORT.md 的"疑问"里写出来，按最保守的理解执行，不要猜。
```

## 2. 回报格式

`MANIFEST.csv` 列：
`asset_id,beat_or_timecode,purpose,file,type,source,source_url,license,author,resolution,duration_s,sha1,status,agent,notes`

`status` 只能是：`delivered` / `not_found` / `license_unclear` / `rejected_by_check`。只有负责审核的强模型才能把素材标成 `accepted`。

`REPORT.md` 第一行写状态：`STATUS: done | partial | blocked`；之后写：做了什么、没做成什么、疑问、各子 Agent 的分工。

交付目录还应包含：`previews/`（每条视频 3 帧接触表）和 `license_proof/`（来源页截图）。

## 3. 给执行 Agent 的通用开场提示词

```
你是执行 Agent。先完整阅读当前目录的 TASK.md，严格按它执行，最后写 MANIFEST.csv 和 REPORT.md。
所有文本文件用 UTF-8 读写。可以把搜索、下载、初筛分给子 Agent，你负责合并与核对。
所有写入只能在当前目录内；禁止删除任何文件；不覆盖已有文件。只以任务单为准，不依赖任何聊天记录。
```

## 4. 登录态网页任务的写法

需要登录态网页（例如图生视频站点）时：

- 写明"可以使用 Chrome 标签页接口或 computer use，哪个能用用哪个，用户已授权"，不要限制操作方式。
- 写明"额度用完就停止并回报，不要购买任何额度"。
- 这类任务交给桌面版 Agent，由用户粘贴提示词；命令行版没有桌面授权通道。

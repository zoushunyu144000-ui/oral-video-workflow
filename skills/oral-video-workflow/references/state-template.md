# WORKFLOW_STATE.md 模板

复制到项目目录并随进度更新。每一步开始前先读它；关卡未通过就停下等用户。

```markdown
# 工作流状态 · <项目名>

- 当前阶段：<例：4 粗剪执行>
- 当前版本：<例：v1>
- 平台与规格：<例：YouTube · 16:9 · 1080p · −14 LUFS>
- 偏好文件：PREFS.md

## 关卡
| 关卡 | 内容 | 状态 | 用户决定（原话）|
|---|---|---|---|
| ◆1 | 粗剪表 | 待确认 / 已通过 | |
| ◆2 | 时间轴锁定（粗剪预览已听） | | |
| ◆3 | 方案与分镜表 | | |
| ◆4 | 样式 / 配乐 / 封面小样 | | |
| ◆5 | 成片审片 | | |

## 用户已认可、不能悄悄丢掉的内容（锁定清单）
- <例：冷开场结构；字幕样式；某段内容"保留">

## 用户否决、不要再提议的
- <例：画面右上角叠小字旁注>

## 版本记录
| 版本 | 日期 | 改了什么 | 来自哪条意见 |
|---|---|---|---|
```

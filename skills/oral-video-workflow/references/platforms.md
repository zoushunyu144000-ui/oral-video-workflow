# 平台档案

发布平台决定画幅、时长、字幕大小、封面规格，也决定标题、简介、关键词怎么写，所以**在第 1 步就问清平台**。这里只给档案模板和一个例子。**具体字数、尺寸上限以平台当前规则为准，使用前请核实**，不要把这里的数字当成事实。

## 档案模板（每个平台一份）

```markdown
# 平台：<名称>

- 画幅与分辨率：
- 常见时长：
- 封面规格：
- 标题：字数上限 / 写法特点 / 是否带系列名
- 简介：结构（钩子 → 内容要点 → 引用与来源 → 章节时间戳 → 系列导航 → 行动号召）
- 关键词 / 话题标签：数量与写法
- 字幕：是否上传字幕文件、格式
- 素材与音乐署名：放在哪里
- 其他平台特有的限制：
```

## 例：YouTube（横屏长视频）

- 画幅：16:9，1080p；封面常用 1280×720
- 标题：给 2–3 个候选，推荐一个；把最有信息量或最有悬念的词放前面；系列视频带系列与集数
- 简介：开头两三行是钩子（折叠前能看到的部分）；中间是内容要点和引用；然后是**章节时间戳**（`0:00 标题`，第一条必须从 0:00 开始）；系列导航；一句行动号召
- 标签：简介末尾放少量相关话题标签
- 署名：CC-BY 素材与音乐必须在简介里按作者要求署名；AI 生成画面注明是情景重现
- 上限：标题、简介、标签都有字符上限，**使用前核实当前数值**

## 发布文案放在工作流的哪一步

| 时点 | 做什么 | 原因 |
|---|---|---|
| 第 6 步（方案） | 标题候选、钩子、关键词、简介草案 | 标题和钩子会影响冷开场怎么写 |
| 第 8 步（小样） | 封面 2–3 版，让用户选 | 封面和画面风格同源，早定早省返工 |
| 第 12 步（出包） | 章节时间戳、音乐与素材署名、最终简介 | 必须等时间线和音乐定稿 |
